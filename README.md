## Development

```bash
npm install
npm run dev
```

Open http://localhost:5173/

## Build

```bash
npm run build
npm run preview
```

## Deploy (Vercel)

```bash
npx vercel link --yes --project ayoub-portfolio
npx vercel deploy --prod --yes
```

Framework: **Vite** · Output: `dist` · `vercel.json` included for SPA routing.
